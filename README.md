## Book reviews automation

Anything tagged `#book` in [`ubiquitous-enigma/sources`](https://github.com/ubiquitous-enigma/sources) (in YAML frontmatter or inline as `#book`) is picked up by `.github/workflows/books.yml` once a day and rendered on `books.html`.

Recognised frontmatter fields:

| Field | Meaning |
|---|---|
| `title` | Book title (falls back to first H1, then filename) |
| `author` | Author name |
| `status` | `reading`, `finished`, `to-read`, `paused`, `dropped` |
| `rating` | Numeric, 1–5 or 1–10 |
| `finished` / `read` / `completed` | Date you finished |
| `summary` / `description` / `review` | Short summary (falls back to first paragraph) |
| `tags` | List or array; needs to include `book` |

To trigger an update without waiting for the schedule, run the workflow manually from the **Actions** tab.

## Trophies automation

`.github/workflows/main.yml` refreshes `trophies.json` daily by hitting the PSN API. Required secrets: `PSN_NPSSO`.
